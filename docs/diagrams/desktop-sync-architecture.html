idiolect — one product, identical UX everywhere, per-OS adapters underneath

The same app, the same tray, the same features on Linux · macOS · Windows. It already works this way: a portable core (capture via cpal, whisper ASR, history, translation, the sync server, training, the dashboard, and the tray menu) plugs into ports. Only the adapters behind two ports are OS-specific — text injection (InputMethodPort) and tray rendering (TrayPort). Nothing is added or removed per OS — like for like.
