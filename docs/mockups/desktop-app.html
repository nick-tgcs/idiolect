idiolect — the desktop app (cross-platform sync & training)

A standalone Linux / macOS / Windows app replaces the three-terminal sync mess. It runs the pairing + ingest server in the background behind a tray / menu-bar icon, so phone corrections sync automatically with zero commands. Two cards: Phones (pair by QR, see paired devices, unpair) and Learning (new-correction count, one-click Train personal model, and an Auto-train toggle that is off by default). Training runs in a crash-isolated trainerctl subprocess and, on success, atomically serves the improved model to your phones — and on Linux the running daemon hot-reloads it so your PC dictation upgrades too. Styled to match the phone app (periwinkle on slate).
